## BDL-Integrated Calibration Maintenance Management System

The BDL Integrated Calibration Management & Validation System is a web-based application developed for Bharat Dynamics Limited (BDL) Quality Management Department. The system streamlines the management, monitoring, validation, and reporting of calibration activities for equipment and instruments used across departments.

The application provides a centralized platform for tracking calibration schedules, maintaining equipment records, generating reports, and visualizing calibration performance metrics.

#### Features

* Calibration equipment management
* Calibration schedule tracking
* Validation record maintenance
* Dashboard with analytics and charts
* Data filtering and searching
* Excel import/export functionality
* PDF report generation
* Interactive data tables
* Responsive user interface
* Real-time notifications and alerts
